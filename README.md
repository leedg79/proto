# FRET LAB — 오디오 멈춤 대응·릭 메뉴 개편(v2.10.0)

기타 학습·연습 관리 PWA임. 1단계에서 모든 모듈이 공통으로 쓰는 세션·기록·학습일지·백업·메트로놈을 만들었고, 2단계에서 Notes 모듈의 Note Finder를 구현함

## 오디오 멈춤 대응·마이크·릭 메뉴 개편 (v2.10.0)
아이폰 + NUX Mighty Plug Pro(USB-C) 실사용 리뷰 반영
- 오디오 멈춤 대응: 소리를 낼 때마다 오디오 시계가 실제로 흐르는지 확인하고, 멈췄으면 오디오를 새로 만듦(재생기·마이크 연결도 정리). 오디오 켜기·음원 불러오기·입력 분석기 준비에 시간 제한. 세션·백킹 화면에서 멈추면 위쪽에 "오디오가 멈춤 · 다시 연결" 안내. 평가 시트에 오디오 상태 한 줄(상태·Hz·다시 연결 횟수·입력 장치)
- 마이크를 연 뒤 반주를 시작(마이크를 여는 순간 아이폰 오디오 경로가 바뀌어 재생이 끊기는 것을 피함)
- Technique: 판정·보정 중에도 이전·다음·종료 가능(진행 중 판정 취소), 판정에 시간 제한
- 마이크 기본 켬(마지막 선택 기억), 세션 바 마이크 버튼으로 바로 켜고 끔. 연습 화면 위에 입력 크기 막대·들린 음·판정 문구(16px, 2줄) 항상 표시
- 노트 찾기 판정: 줄 수만큼(6현 = 6번, 3~4현 = 줄 수) 맞는 음을 치면 통과, 시간 = 첫 어택 ~ 마지막 맞은 어택, 정확도 = 맞은 음 ÷ 친 음. 마이크로는 줄을 구분할 수 없어 줄은 판정하지 않음
- 코드 구성음 평가 삭제(코드 찾기·연속 코드·Play Session·장르별 컴핑에는 마이크 평가 없음)
- 순서 판정(스케일·릭): 옥타브를 잘못 들은 음은 틀림으로 치지 않음, 구간이 바뀌는 순간 늦게(0.3초)·일찍(0.25초) 친 음도 맞는 구간으로
- Notes: 6현 전체가 N1, 무작위 3~4현이 N2(저장 기록과 맞도록 아이디 n2·n1 유지), 무작위 현은 줄 순서도 무작위
- 단계별 코스: 1단계에 오픈 코드 진행 반주, 2단계에 마이너 펜타토닉 모양(맞바꿈)
- 릭 메뉴: 릭 홈 = 기본 릭 모음(기존 135개, 난이도 순서·분류별 연습 메뉴 유지) · 장르 8개(블루스·네오소울·R&B·팝·펑크·록·메탈·재즈) · 전체 릭 목록(분류·기타리스트·난이도·검색) · 내 릭
  - 장르 화면: 한 화면에서 기타리스트 + 난이도(초급·중급·고급) → 릭 목록. 릭이 없으면 "준비 중"
  - 릭을 누르면 세션 전 설정(연습 방식·마이크·판정·키·시범 소리) → 세션
  - 혼자 익히기: 박자 없이 한 음씩, 다음 음을 악보·지판에 강조, 마이크가 맞는 음을 들으면 다음 음으로(기록 없음), 구간(마디) 반복, 이 음 듣기. 끝까지 3번 = 완료 1회
  - 박자 맞춰 치기: 준비 4박 → 릭 반복, 판정을 켜면 음마다 박자·음 높이 판정(통과 2번 = 완료 1회), 끄면 끝까지 3번 = 완료 1회
- 장르 릭 추가 방법: js/modules/licks/genre-data.js의 GENRES(기타리스트)와 GENRE_LICK_ROWS(릭 한 줄씩)에 넣으면 메뉴·목록에 바로 나타남. 형식은 파일 머리말 참고(4마디·24프렛까지)

## 디자인 개편 (v2.9.0)

- 색·모양: 짙은 남색 바탕(#0F1628), 테두리 없는 둥근 카드, 알약 모양 버튼, 연두 주 버튼(#B6F36C) 하나. 상단 바는 아이콘만(뒤로·홈, 홈 화면에서는 데이터 관리·학습일지)
- 홈: 최근 연습량 꺾은선 그래프(1주 = 하루 7점, 1달 = 최근 28일을 주 4점). 총량·화성학(Notes·Chords·Scales·Ear Lab)·테크닉(Rhythm·Technique·Licks) 3선과 기간 합계. 아래에 모듈 7개 + 백킹 트랙 아이콘 타일(설명 없이 이름만), 모듈/단계 전환
- 세션 화면: 위 한 줄(레벨·과제명, 시간, 일시정지 원형 버튼, 종료) + 둘째 줄(완료 횟수, 주제, 평가·설정 버튼). 설정 변경·연주 평가는 아래에서 올라오는 시트로 옮김. 평가를 켜면 판정 결과는 둘째 줄 아래 한 줄로 표시
- 연습 조작(시작·정답 확인·판정, 이전·다음, BPM)은 화면 맨 아래에 붙어 스크롤 없이 누를 수 있음. 내용이 짧으면 화면 아래, 길면 스크롤해도 아래에 고정
- 연습 시작 전: 큰 원형 "연습 시작" 버튼. 과제 설정 화면의 "세션 시작"도 아래에 고정
- Technique: 마이크 입력 장치·감도·입력 확인은 "마이크·입력 설정" 접기 안으로, 시연 듣기는 이전·다음 사이로
- 백킹 트랙: 진행·스타일을 가로로 넘기는 칩으로, 머리말 제거
- 화면 진입 단계(홈 → 모듈 → 레벨 → 과제 설정 → 세션)는 그대로

## 홈 단계별 보기 (v2.8.0)

- 홈에서 "모듈별 / 단계별" 전환. 고른 보기와 단계는 기억함
- 단계별: 입문·초보·초급·중급·고급 5단계, 단계마다 목표 한 줄과 항목 목록. 항목은 기존 과제로 가는 바로가기이고 학습 주제·설정(제한시간·BPM)을 미리 골라 둠(입문 7 · 초보 11 · 초급 16 · 중급 17 · 고급 13, 모두 64개)
- 콘텐츠가 아직 없는 자리(중급·고급 테크닉 심화, 릭·변형 심화, 고급 리듬)는 "준비 중" 항목으로만 둠(5개)
- 코스에서 들어간 설정은 그 과제 화면·세션에만 적용되고 모듈 메뉴의 내 설정은 바뀌지 않음. 과제 화면 위에 어느 코스 항목인지 표시
- 기록은 원래 모듈·레벨·과제로 쌓이고, 항목마다 해 본 세션 수와 단계별 "해 본 항목 n/전체" 표시
- Chords 레벨 이름을 단계 이름과 겹치지 않게 바꿈: C1 기본 코드 · C2 바레·확장 코드 · C3 재즈 보이싱 · C4 응용 보이싱 · C5 반주·코드 멜로디
- 파일: js/data/courses.js

## 연주 평가 · 마이크 (v2.7.0)

- Notes·Chords·Rhythm·Scales·Licks·Technique 세션 화면 오른쪽(휴대폰은 아래)에 "연주 평가" 패널을 둠. 기본은 OFF, 켜면 마이크(Technique에서 고른 입력 장치·감도·보정 지연을 같이 씀)로 연주를 듣고 문제마다 판정함. Ear Lab에는 없음
- 소리 분석: 단음은 YIN 음 높이(가장 가까운 반음), 코드는 스펙트럼을 12음 이름별 세기(크로마)로 모아 구성음 판정, 박자는 기존 어택 감지
- 판정 방식(화면별)
  - Note Finder: 문제 음(고른 줄 0~15프렛 안의 위치)이 잡히면 통과, 그 전의 다른 음은 실수. 수행시간 = 문제가 나온 뒤 맞는 음이 잡힐 때까지
  - Random Chord·연속 코드 찾기: 코드 구성음이 잠깐(약 75ms) 이어지면 통과. 구성음 밖 음이 계속 들리면 실수. 연속 코드는 코드가 바뀌는 박마다 앞 코드를 마감
  - Play Session·장르 컴핑: 마디(코드)마다 화면 운지의 구성음으로 판정
  - Chord Melody 따라 치기·Rhythm 프레이즈·Lick 반주 주고받기(응답 차례): 음마다 제때(박 ±120ms) 맞는 음을 쳤는지. 놓친 음·다른 음을 번호로 기록
  - Rhythm 패턴·리듬 읽기: 어택이 악보 칸에 맞았는지(박 ±100ms). 놓친 박("2마디 3박 &")과 불필요한 어택 수 기록. 시범 듣기 모드는 평가하지 않음
  - Scales 문제형(근음 위치·모드 바꾸기 등): 제한시간 동안 친 음이 스케일 안인지 + 구성음을 다 쳤는지. 수행시간 = 모든 구성음을 친 순간
  - 시작음·블록 학습·블록 이동: 정해진 음 순서대로 쳤는지, 틀린 자리("5번째 음(A → B♭)") 기록
  - Chord-Scale: 마디마다 친 음이 그 코드의 스케일 안인지(즉흥이라 다 칠 필요 없음)
  - Lick 익히기: 릭을 TAB 순서대로(벤딩으로 올라가는 음 인정) 다 치면 통과 기록 후 같은 릭으로 다시 평가. Lick 옮기기는 옮긴 키의 음 순서(옥타브 무관), 변형은 릭의 스케일 안인지
  - Technique: "판정" 결과(맞춘 어택 비율·박자 오차·놓친 음 번호·불필요한 어택)를 그대로 기록
- 기록: 세션 기록에 평가 횟수·통과·정확도·평균 수행시간·박자 오차·실수 수·자주 틀린 곳(상위 5개)·문제별 기록(최근 200건)을 넣음. 결과 화면과 학습일지 기록 상세에 표시. 완료 0회 세션은 지금처럼 기록하지 않음
- 주의: 실제 기기(아이폰 마이크·iRig·MP-3) 정확도는 아직 확인 전임. 반주·클릭이 스피커로 나오면 마이크에 섞이므로 이어폰을 권장함. 화음·빠른 패시지·벤딩은 음 높이 인식이 흔들릴 수 있음
- 파일: js/eval/pitch-core.js(YIN·크로마·코드 판정), eval-core.js(대상별 판정·누적), evaluator.js(마이크 분석·세션 기록), targets.js(화면별 대상 만들기)

## Ear Lab · 입력 장치 (v2.6.0)

- E1 음 이름 청음: 한 음을 듣고 이름 고르기. 음역(저음·중음·고음·전체), 반음 포함 12음 / 자연음 7음, 기준음 C 먼저, 음색(일렉·어쿠스틱·베이스). 틀리면 정답 음과 내가 고른 음을 비교해 들음. 24문제 = 완료 1회
- E2 음정 청음: 상행·하행·동시·섞기, 학습 주제(2·3도 / 4·5도 / 6·7도 / 옥타브·복합)의 음정만 보기로 나옴. 정답 뒤에 기억법(널리 쓰이는 곡 첫 음정) 표시. 24문제 = 완료 1회
- E3 선율 채보: 으뜸화음 뒤 3~6음 선율을 도수(낮은 5 ~ 높은 1)로 순서대로 입력. 메이저·마이너, 순차·도약, C 고정·무작위 키. "리듬까지"를 켜면 음높이를 맞힌 뒤 리듬 악보 3개 중 정답 고르기. 10문제 = 완료 1회
- E3 화성 청음: 메이저·마이너 3화음의 자리바꿈(기본·1전위·2전위) 또는 맨 위 음(근음·3음·5음). 펼쳐 듣기 가능. 10문제 = 완료 1회
- E3 코드 청음: 트라이어드 5종, 7th 5종, 텐션 6종(add9·maj9·9·m9·7♭9·13), 코드 진행 6가지. 10문제 = 완료 1회
- E4 프레이즈 채보: Blues·Rock·Funk·Jazz 릭(장르별로 릭 목록에서)을 듣고 지판(6줄 × 0~17프렛)에서 음을 순서대로 누름. 음높이만 맞으면 어느 자리든 정답, 확인 뒤 정답 TAB 표시. 앞 4·6·8음 / 전체, 속도 60·80·100, 느리게 듣기. 프레이즈 5개 = 완료 1회
- Technique 입력 장치: 아이폰이 정한 기본 입력 또는 목록에서 직접 선택(목록은 마이크 권한 뒤에 나옴), "지금 듣는 입력" 이름 표시, 기타 소리를 이어폰으로 같이 듣는 입력 모니터링, 오디오 인터페이스·이어폰 연결 안내. iPhone이 외부 입력으로 경로를 바꾸도록 마이크를 열기 직전 오디오 세션을 잠깐 "auto"로 둠
- 주의: iPhone Safari(웹앱)는 USB 인터페이스가 목록에 보여도 실제로는 아이폰 마이크로 녹음하는 경우가 보고되어 있음(WebKit 버그 211192). "입력 확인"을 켜고 손뼉에 반응하지 않고 기타 줄에만 반응하는지로 확인
- 모든 과제에 실제 콘텐츠가 붙어서 예전 임시 화면(시험용 완료 버튼·메트로놈 패널)은 더 이상 나오지 않음

## Technique 보완 (v2.5.1)

- 마이크 감도: 민감(앰프 없는 일렉처럼 작은 소리) / 보통 / 둔감(잡음이 많은 곳). 세션 설정과 연습 화면에서 바로 바꿀 수 있음
- 입력 확인: 8초 동안 치는 대로 잡힌 어택을 시간 띠에 점으로 보여 주고 개수를 셈. 친 횟수와 비슷하면 지금 위치·감도로 판정 가능
- 오디오 인터페이스(iRig 등) 직접 연결은 중장기 검토 과제로 남김

## Technique 단계 (v2.5.0)

- 새 모듈 Technique: T1 왼손 기초(크로매틱·스파이더·손가락 독립·넓혀 짚기·자리 옮기기), T2 벤딩·비브라토, T3 피킹(얼터네이트·줄 넘기·스트링 스킵·이코노미·트레몰로·코드톤·스케일 — 예전 Rhythm R3 Picking 포함), T4 뮤팅·표현(팜뮤트·스타카토·레가토·슬라이드), T5 응용 연습곡. 연습곡 55개(1~2마디, 오선+TAB, 권장 시작·목표 BPM)
- 박자 판정: 마이크로 내가 친 소리의 시작점(어택)을 잡아 악보의 음표·쉼표 박자와 비교. 해머온·풀오프·슬라이드·벤딩 내리기 음은 어택이 약해 판정에서 빼고, 쉼표 자리에서 친 소리는 "불필요한 어택"으로 셈
  - 통과 기준: 필수 어택의 90% 이상을 판정 창(가장 짧은 음 간격의 40%, 최대 90ms) 안에서 침, 그중 80% 이상이 ±50ms 안, 평균 오차 40ms 이하, 불필요한 어택은 필수 수의 5%(최소 1개)까지
  - 결과: 박에 맞춘 비율, 평균 오차, ±50ms 비율, 불필요한 어택, 빠름·늦음 경향, 빠진 음 수. 악보 음표를 초록(±25ms)·노랑(±50ms)·주황(그 이상)·빨강(못 잡음)으로 표시
- 템포 사다리: 통과하면 BPM을 +2·4·6·8(설정) 올리고, 2번 연속 실패하면 내림. 연습곡별 최고 통과 BPM을 기억하고 다음에 "내 최고 기록부터" 시작 가능. 통과 3회 = 완료 1회
- 박자 보정: 조용히 1초(소음 수준) → 클릭 4번 동안 치지 않기(스피커 클릭이 마이크에 들어가는지) → 클릭 8번에 맞춰 뮤트한 줄 피킹으로 기기 지연을 재서 판정에서 뺌. 이어폰 사용 권장
- 음 높이(맞는 음을 쳤는지)·쉼표에서 소리를 끊었는지·벤딩 높이 판정은 녹음·마이크 판정 단계에서 추가
- iPhone에서 마이크를 쓰는 동안 오디오 세션을 녹음·재생 겸용으로 바꾸고, 판정 화면을 나가면 마이크를 끔

## 3단계 ② 추가 (v1.4.0): 연속 코드 찾기(당시 이름 BPM Chord Finding)

- C1~C4에서 학습 주제를 골라 시작 → 세션 설정: BPM 40~160(기본 70), 현재 코드 운지 다이어그램 표시 여부
- "연주 시작"을 누르면 1마디(4박) 준비 박 뒤 2박마다 코드가 바뀜(마디당 코드 2개). 현재 코드·다음 코드 미리보기·마디 번호·박 표시
- 8마디(코드 16개)를 끝까지 치면 완료 1회 자동 기록, 이어서 새 16개로 계속
- 박자와 코드 변경 시각은 오디오 시계 기준(메트로놈 클릭과 정확히 맞음). BPM은 연습 중 ±1·±5 조절, 다음 박부터 적용
- 일시정지·앱 이탈 시 연주가 멈추고, 다시 시작하면 멈춘 코드부터 준비 박을 세고 이어감
- 다이어그램은 그 코드의 가장 자주 쓰는 운지 1개를 표시

## 수정 (v1.3.1): 자주 쓰는 운지만 표시

- Random Chord Finding 정답과 Chord Dictionary 모두 자주 쓰는 운지를 8개 이내로, 많이 쓰는 순서대로(왼쪽 위부터) 표시함
- 순위 기준: 보이싱 종류의 일반적 사용 빈도(오픈 → 바레 → Shell·Drop 2·텐션 → 트라이어드 → Drop 3 → Open·Quartal) → 많이 쓰는 현 묶음(트라이어드 1-2-3·2-3-4번 현, Drop 2 1~4·2~5번 현 등) → 12프렛 이하 → 넓은 벌림·손가락 4개 감점 → 베이스가 근음인 운지 가점
- 같은 모양이 12프렛 위에 반복되면 낮은 쪽만, 다른 분류에서 같은 운지가 나오면 하나만 표시

## 3단계 ① 추가 (v1.3.0): 코드 엔진 · Chord Dictionary · Random Chord Finding

- **코드 엔진**: 주제별 보이싱 규칙으로 운지를 계산함(오픈 코드 표, 파워 코드, 연속 3현 밀집 트라이어드, E폼·A폼 바레, CAGED 5폼, Drop 2·Drop 3(전위는 실제 베이스 음 기준), Shell(R-3-7/R-7-3), 텐션(9·maj9·m9·13·m11), 슬래시 코드, 펼친 트라이어드, 4도 쌓기). 0~15프렛, 누르는 음 3칸 폭 이내, 손가락 4개 이내만 표시
- **Random Chord Finding**(C1~C4): 고른 학습 주제로 12문제 출제(근음 12개 한 번씩, 주제 고르게 섞음), 제한시간 3~30초(기본 10초), 정답 확인 시 자주 쓰는 운지를 코드 다이어그램으로 표시(v1.3.1부터 8개 이내), 12문제 = 완료 1회 자동 기록
  - 전위·현 그룹·CAGED 폼·Drop 현 묶음 같은 조건이 문제에 함께 제시되고 정답도 그 조건의 운지만 보여 줌
  - 대리 코드는 "G7의 트라이톤 대리 코드"처럼 질문형으로 출제
- **Chord Dictionary**: 근음 12개 × 코드 종류 17개, 자주 쓰는 운지 8개 이내 표시(v1.3.1). 세션 기록 없음
- Play Session은 v1.5.0에서 구현

## 공통 기능 추가 (v1.2.0): 학습 주제 선택

- 과제를 누르면 시작 전에 그 레벨의 학습 주제를 체크 목록으로 고름(1개 또는 여러 개, 1개 이상 필수, 전체 선택·해제, 마지막 선택 기억)
- 주제가 없는 과제(Note Finder, 음 이름 청음, 선율 채보, 화성 청음, S5)는 주제 선택 없이 시작
- 고른 주제는 세션 화면 태그, 세션 기록, 텍스트 학습일지 상세에 표시됨
- 일간 학습일지는 과제 아래에 주제 조합별 연습시간·완료 횟수를 보여 줌(여러 주제를 섞은 세션은 그 조합으로 집계, 고른 순서는 상관없음)
- 키·BPM 같은 연습 조건은 각 모듈의 연습 화면을 만들 때 추가함

## 2단계에서 추가·변경된 것 (v1.1.0)

- **Note Finder**: 기존 FRET LAB의 흐름(문제 카드 → 제한시간 → 정답 확인 → 지판 정답 → 다음 문제)을 그대로 옮김
  - N1: 매 문제 무작위 3~4개 현 / N2: 6개 현 전체(0~15프렛)
  - 샤프·플랫 모두 출제(C♯/D♭처럼 이름이 둘인 음은 표기를 무작위로 고름, E♯·C♭ 등 드문 표기 제외)
  - 12개 음높이를 섞어 한 번씩 출제, 12개 모두 정답 확인까지 마치면 완료 1회 자동 기록(순환이 바뀔 때 같은 음 연속 없음)
  - 세션 시작 전 설정: 제한시간 1~15초(마지막 값 기억), 연습 중에도 변경 가능
  - 시간이 끝나면 정답 자동 표시. 제한시간은 실제 연습시간 기준이라 일시정지·앱 이탈 중에는 멈춤
  - 화면 이동·앱 재실행 후에도 순환 진행과 현재 문제를 그대로 이어감
  - 정답 지판은 15프렛까지 화면 폭에 맞춰 표시(기존 앱은 13~15프렛 정답이 그림 밖으로 나가던 문제 수정)
- **세션 기록에 설정값 저장**: 텍스트 학습일지 상세에 "설정: 제한시간 N초" 표시
- **목록 변경**: Chords C5 응용 레벨 신설(보이스 리딩·장르별 컴핑·코드 멜로디, 과제는 Play Session·Chord Dictionary), C4는 대리 코드·슬래시 코드·Open·Quartal Voicing, S4 Modes는 7개 포지션 단위(완료 7개 포지션 1사이클)
- 나머지 모듈(Chords·Scales·Rhythm·Ear Lab)은 1단계와 같이 시험용 완료 버튼으로 동작함

## 1단계 기능

- 홈 화면, 5개 모듈 → 레벨 → 과제 진입 (레벨·과제 목록은 결정 사항 표 기준)
- 세션 시작·일시정지·재개·종료 (시작 버튼을 눌러야만 시작)
- 실제 연습시간 계산: 일시정지·앱 이탈 시간 제외, 시각 차이로 계산
- 앱 이탈(다른 앱 전환·화면 잠금) 시 자동 일시정지, 복귀 후 재개 버튼으로 이어가기
- 진행 중 세션 유지: 홈으로 가도 하단에 진행 중 표시, 앱을 껐다 켜도 복구
- 세션 종료 시 기록 저장(기록하지 않고 버리기도 가능)
- 완료 횟수는 연습시간과 별도로 집계 (1단계는 시험용 "완료 1회 기록" 버튼)
- 학습일지: 연간(모듈별 누적·월별) · 월간(달력, 모듈·레벨별) · 일간(모듈·레벨·과제별) · 텍스트 기록(세션별 상세, 모듈 필터, 개별 삭제)
- JSON 백업(아이폰 공유 시트로 파일 저장) · 복원(합치기/전체 교체) · 7일 이상 미백업 시 홈 알림
- 메트로놈: 오디오 시계 기준 예약 방식, BPM 30~300, 2/4·3/4·4/4·6/4, 첫 박 강세, 박 표시등
- 오프라인 실행, 홈 화면 앱 설치, 세로·가로 화면 대응, 연습 중 화면 꺼짐 방지(지원 기기)

## GitHub Pages 배포

PC 브라우저 기준임 (아이폰에서는 폴더째 업로드가 어려움)

1. GitHub에서 **New repository** → 이름 입력(예: `fretlab`) → **Public** → Create
2. 새 저장소 화면에서 **uploading an existing file** 클릭
3. ZIP을 푼 폴더 **안의 내용 전부**(index.html, css, js, icons 등)를 업로드 창에 끌어다 놓기. 폴더 구조가 그대로 올라가야 함 → **Commit changes**
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, 폴더 **/(root)** → Save
5. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/fretlab/`)로 접속

### 아이폰에 설치

1. 아이폰 **Safari**로 위 주소 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 이후에는 반드시 홈 화면 아이콘으로 실행함. Safari 탭과 홈 화면 앱은 저장 공간이 따로라서 기록이 섞이지 않고, 홈 화면 앱이 기록 보존에 유리함

### 수정본을 다시 올릴 때

ZIP을 푼 파일 전체를 같은 위치에 다시 업로드함(같은 이름 파일은 덮어씀). `sw.js`의 `CACHE` 이름은 버전마다 이미 올려 두었음(이번 v2.2.0). 아이폰에서는 인터넷이 연결된 상태로 앱을 완전히 닫았다가 두 번 정도 다시 열면 새 버전이 반영됨. 데이터 관리 화면의 앱 버전이 2.2.0이면 반영된 것임. 기존 기록은 그대로 유지됨

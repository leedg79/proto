# FRET LAB — 3단계 Chords 완료(Play Session까지)

기타 학습·연습 관리 PWA임. 1단계에서 모든 모듈이 공통으로 쓰는 세션·기록·학습일지·백업·메트로놈을 만들었고, 2단계에서 Notes 모듈의 Note Finder를 구현함

## 3단계 ③ 추가 (v1.5.0): Play Session · 연속 코드 찾기 이름 변경

- **Play Session**(C1~C5): 세션 설정에서 키(장조 12개)·진행 유형(Pop·Ballad·Jazz ii-V-I·Bossa Nova)·BPM 40~160(기본 80)을 고르고 시작
  - A-A-B-A′(각 8마디) 32마디 진행을 만들어 1마디 준비 박 뒤 메트로놈에 맞춰 연주. 마디당 코드 1~2개
  - 학습 주제를 여러 개 고르면 섹션마다 하나씩 맡음(예: A는 Shell, 두 번째 A는 Drop 2)
  - 주제별 화성: 3화음 주제는 3화음, 7th 계열 주제는 7th 코드, 텐션은 9th 계열, 파워 코드는 파워 코드
  - 주제별 변형: 대리 코드는 I로 가는 V7을 ♭II7로, 슬래시는 다음 코드로 반음·온음 이어지는 베이스(예: G/B → C), 디미니시드·어그먼티드·서스펜디드는 Vsus4 → V, V → V+ → I, I → I+
  - 보이싱: 오픈·바레·파워·7th·텐션은 가장 자주 쓰는 운지, 나머지(트라이어드·Shell·Drop·보이스 리딩 등)는 앞 코드와 가장 가까운 운지를 골라 손 이동을 줄임
  - 현재·다음 코드 다이어그램, 섹션·마디 표시, 실시간 코드표(현재 마디 강조). 코드표의 마디를 누르면 그 마디부터 연습 가능
  - 32마디를 빠짐없이 연주하면 완료 1회(일시정지 후 이어서 쳐도 인정, 건너뛴 마디가 있으면 미인정). 끝나면 코드표 PNG 저장(아이폰은 공유 시트)
  - C5: 보이스 리딩만 선택 가능, 장르별 컴핑·코드 멜로디는 악보 단계에서 추가 예정으로 비활성 표시
- **이름 변경**: BPM Chord Finding → "연속 코드 찾기 · Sequential Chord Finding". 화성 진행과 무관하게 무작위 출제이며, 16개 안에서 같은 근음이 연달아 나오지 않게 보강

## 3단계 ② 추가 (v1.4.0): 연속 코드 찾기(당시 이름 BPM Chord Finding)

- C1~C4에서 학습 주제를 골라 시작 → 세션 설정: BPM 40~160(기본 70), 현재 코드 운지 다이어그램 표시 여부
- "연주 시작"을 누르면 1마디(4박) 준비 박 뒤 2박마다 코드가 바뀜(마디당 코드 2개). 현재 코드·다음 코드 미리보기·마디 번호·박 표시
- 8마디(코드 16개)를 끝까지 치면 완료 1회 자동 기록, 이어서 새 16개로 계속
- 박자와 코드 변경 시각은 오디오 시계 기준(메트로놈 클릭과 정확히 맞음). BPM은 연습 중 ±1·±5 조절, 다음 박부터 적용
- 일시정지·앱 이탈 시 연주가 멈추고, 다시 시작하면 멈춘 코드부터 준비 박을 세고 이어감
- 다이어그램은 그 코드의 가장 자주 쓰는 운지 1개를 표시

## 수정 (v1.3.1): 자주 쓰는 운지만 표시

- Random Chord Finding 정답과 Chord Dictionary 모두 자주 쓰는 운지를 8개 이내로, 많이 쓰는 순서대로(왼쪽 위부터) 표시함
- 순위 기준: 보이싱 종류의 일반적 사용 빈도(오픈 → 바레 → Shell·Drop 2·텐션 → 트라이어드 → Drop 3 → Open·Quartal) → 많이 쓰는 현 묶음(트라이어드 1-2-3·2-3-4번 현, Drop 2 1~4·2~5번 현 등) → 12프렛 이하 → 넓은 벌림·손가락 4개 감점 → 베이스가 근음인 운지 가점
- 같은 모양이 12프렛 위에 반복되면 낮은 쪽만, 다른 분류에서 같은 운지가 나오면 하나만 표시

## 3단계 ① 추가 (v1.3.0): 코드 엔진 · Chord Dictionary · Random Chord Finding

- **코드 엔진**: 주제별 보이싱 규칙으로 운지를 계산함(오픈 코드 표, 파워 코드, 연속 3현 밀집 트라이어드, E폼·A폼 바레, CAGED 5폼, Drop 2·Drop 3(전위는 실제 베이스 음 기준), Shell(R-3-7/R-7-3), 텐션(9·maj9·m9·13·m11), 슬래시 코드, 펼친 트라이어드, 4도 쌓기). 0~15프렛, 누르는 음 3칸 폭 이내, 손가락 4개 이내만 표시
- **Random Chord Finding**(C1~C4): 고른 학습 주제로 12문제 출제(근음 12개 한 번씩, 주제 고르게 섞음), 제한시간 3~30초(기본 10초), 정답 확인 시 자주 쓰는 운지를 코드 다이어그램으로 표시(v1.3.1부터 8개 이내), 12문제 = 완료 1회 자동 기록
  - 전위·현 그룹·CAGED 폼·Drop 현 묶음 같은 조건이 문제에 함께 제시되고 정답도 그 조건의 운지만 보여 줌
  - 대리 코드는 "G7의 트라이톤 대리 코드"처럼 질문형으로 출제
- **Chord Dictionary**: 근음 12개 × 코드 종류 17개, 자주 쓰는 운지 8개 이내 표시(v1.3.1). 세션 기록 없음
- Play Session은 v1.5.0에서 구현

## 공통 기능 추가 (v1.2.0): 학습 주제 선택

- 과제를 누르면 시작 전에 그 레벨의 학습 주제를 체크 목록으로 고름(1개 또는 여러 개, 1개 이상 필수, 전체 선택·해제, 마지막 선택 기억)
- 주제가 없는 과제(Note Finder, 음 이름 청음, 선율 채보, 화성 청음, S5)는 주제 선택 없이 시작
- 고른 주제는 세션 화면 태그, 세션 기록, 텍스트 학습일지 상세에 표시됨
- 일간 학습일지는 과제 아래에 주제 조합별 연습시간·완료 횟수를 보여 줌(여러 주제를 섞은 세션은 그 조합으로 집계, 고른 순서는 상관없음)
- 키·BPM 같은 연습 조건은 각 모듈의 연습 화면을 만들 때 추가함

## 2단계에서 추가·변경된 것 (v1.1.0)

- **Note Finder**: 기존 FRET LAB의 흐름(문제 카드 → 제한시간 → 정답 확인 → 지판 정답 → 다음 문제)을 그대로 옮김
  - N1: 매 문제 무작위 3~4개 현 / N2: 6개 현 전체(0~15프렛)
  - 샤프·플랫 모두 출제(C♯/D♭처럼 이름이 둘인 음은 표기를 무작위로 고름, E♯·C♭ 등 드문 표기 제외)
  - 12개 음높이를 섞어 한 번씩 출제, 12개 모두 정답 확인까지 마치면 완료 1회 자동 기록(순환이 바뀔 때 같은 음 연속 없음)
  - 세션 시작 전 설정: 제한시간 1~15초(마지막 값 기억), 연습 중에도 변경 가능
  - 시간이 끝나면 정답 자동 표시. 제한시간은 실제 연습시간 기준이라 일시정지·앱 이탈 중에는 멈춤
  - 화면 이동·앱 재실행 후에도 순환 진행과 현재 문제를 그대로 이어감
  - 정답 지판은 15프렛까지 화면 폭에 맞춰 표시(기존 앱은 13~15프렛 정답이 그림 밖으로 나가던 문제 수정)
- **세션 기록에 설정값 저장**: 텍스트 학습일지 상세에 "설정: 제한시간 N초" 표시
- **목록 변경**: Chords C5 응용 레벨 신설(보이스 리딩·장르별 컴핑·코드 멜로디, 과제는 Play Session·Chord Dictionary), C4는 대리 코드·슬래시 코드·Open·Quartal Voicing, S4 Modes는 7개 포지션 단위(완료 7개 포지션 1사이클)
- 나머지 모듈(Chords·Scales·Rhythm·Ear Lab)은 1단계와 같이 시험용 완료 버튼으로 동작함

## 1단계 기능

- 홈 화면, 5개 모듈 → 레벨 → 과제 진입 (레벨·과제 목록은 결정 사항 표 기준)
- 세션 시작·일시정지·재개·종료 (시작 버튼을 눌러야만 시작)
- 실제 연습시간 계산: 일시정지·앱 이탈 시간 제외, 시각 차이로 계산
- 앱 이탈(다른 앱 전환·화면 잠금) 시 자동 일시정지, 복귀 후 재개 버튼으로 이어가기
- 진행 중 세션 유지: 홈으로 가도 하단에 진행 중 표시, 앱을 껐다 켜도 복구
- 세션 종료 시 기록 저장(기록하지 않고 버리기도 가능)
- 완료 횟수는 연습시간과 별도로 집계 (1단계는 시험용 "완료 1회 기록" 버튼)
- 학습일지: 연간(모듈별 누적·월별) · 월간(달력, 모듈·레벨별) · 일간(모듈·레벨·과제별) · 텍스트 기록(세션별 상세, 모듈 필터, 개별 삭제)
- JSON 백업(아이폰 공유 시트로 파일 저장) · 복원(합치기/전체 교체) · 7일 이상 미백업 시 홈 알림
- 메트로놈: 오디오 시계 기준 예약 방식, BPM 30~300, 2/4·3/4·4/4·6/4, 첫 박 강세, 박 표시등
- 오프라인 실행, 홈 화면 앱 설치, 세로·가로 화면 대응, 연습 중 화면 꺼짐 방지(지원 기기)

## GitHub Pages 배포

PC 브라우저 기준임 (아이폰에서는 폴더째 업로드가 어려움)

1. GitHub에서 **New repository** → 이름 입력(예: `fretlab`) → **Public** → Create
2. 새 저장소 화면에서 **uploading an existing file** 클릭
3. ZIP을 푼 폴더 **안의 내용 전부**(index.html, css, js, icons 등)를 업로드 창에 끌어다 놓기. 폴더 구조가 그대로 올라가야 함 → **Commit changes**
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, 폴더 **/(root)** → Save
5. 1~2분 뒤 표시되는 주소(`https://아이디.github.io/fretlab/`)로 접속

### 아이폰에 설치

1. 아이폰 **Safari**로 위 주소 접속
2. 공유 버튼 → **홈 화면에 추가**
3. 이후에는 반드시 홈 화면 아이콘으로 실행함. Safari 탭과 홈 화면 앱은 저장 공간이 따로라서 기록이 섞이지 않고, 홈 화면 앱이 기록 보존에 유리함

### 수정본을 다시 올릴 때

ZIP을 푼 파일 전체를 같은 위치에 다시 업로드함(같은 이름 파일은 덮어씀). `sw.js`의 `CACHE` 이름은 버전마다 이미 올려 두었음(이번 v1.5.0). 아이폰에서는 인터넷이 연결된 상태로 앱을 완전히 닫았다가 두 번 정도 다시 열면 새 버전이 반영됨. 데이터 관리 화면의 앱 버전이 1.5.0이면 반영된 것임. 기존 기록은 그대로 유지됨

## 아직 구현하지 않은 기능

- Chords C5 장르별 컴핑·코드 멜로디(악보 단계), Play Session 단조 진행
- 나머지 모듈의 학습 콘텐츠:, Scales(4단계), 악보·TAB 렌더러와 악기 음원(5단계), Rhythm(6단계), Ear Lab(7단계), 장르별 반주(8단계), 녹음(9단계)
- Notes 외 모듈의 완료 횟수 자동 판정 (지금은 시험용 버튼, 각 모듈 구현 시 교체)
- Notes 외 모듈의 세션 시작 전 설정(학습 주제·연습 조건)과 주제별 학습일지 집계
- Chord Dictionary 화면
- 악기 음원·반주 (메트로놈만 있음)
- 클라우드 동기화 (구조만 분리해 둠)

## 알려진 제약

- 아이폰은 앱을 벗어나면 코드 실행이 멈추므로 백그라운드에서 시간 측정·메트로놈은 동작하지 않음 (결정 사항대로 자동 일시정지)
- 무음 스위치가 켜져 있을 때 메트로놈 소리가 나는지는 iOS 버전에 따라 다를 수 있어 실기기 확인이 필요함
- 화면 꺼짐 방지는 기기가 지원하는 경우에만 동작함. 안 되면 설정 → 디스플레이 → 자동 잠금 시간을 늘려야 함
- 세션 날짜는 시작한 날 기준임 (자정을 넘겨도 시작일에 기록)
